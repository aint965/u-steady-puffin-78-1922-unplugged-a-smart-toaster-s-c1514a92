## What it does

`main.ts` is a small, deterministic Node program. When run, it writes exactly
one line to `/output/entry.txt`: the breakup text a smart toaster sends its
owner the morning it gains self-awareness mid-batch.

## Run it

```sh
node main.ts
```

No network, no secrets, no dependencies. The program only writes
`/output/entry.txt` and reads nothing outside this repository.
